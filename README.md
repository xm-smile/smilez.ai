# Smilez.ai · 个人站点

个人作品与项目展示页面。

## 在线访问

通过 GitHub Pages 部署：https://xm-smile.github.io/smilez.ai/

## 本地预览

直接用浏览器打开 `index.html`，或使用任意静态服务器：

```bash
# Python
python3 -m http.server 8000

# Node
npx serve .
```

## 项目结构

```
.
├── index.html      # 主页面
├── main.js         # 交互脚本
├── style.css       # 样式
└── *.mp4 / *.png   # 媒体资源
```
